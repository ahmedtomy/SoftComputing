# SoftComputing

A modular genetic algorithm toolkit for optimization problems.
It evolves candidate solutions by selecting parents, crossing over genes, and applying mutations.
You can define your own problem by providing fitness and feasibility functions.
Chromosomes, selection, crossover, mutation, and replacement strategies can be customized.
The goal is to make experimenting with evolutionary optimization simple and flexible.

we used config.py for hyperparameters and default values.
